# Phase 03 — Verification (2026-11-16)

Codex generated the artwork of concept 2 "Polar Khomus" in two rounds (prompts and Codex's own
notes in `.planning/design/assets/`). Round 1 produced all five files. The knob cap (a flat,
pale disc) and the ornament strip (a thin plain outline) were too weak, so round 2 remade those
two to match the mockups.

| File | Size | Alpha | Checked |
|---|---|---|---|
| `Resources/Art/background.png` | 2200 × 1375 | no | dark midnight leather with faint fur at the edges and a faint diamond pattern; calm everywhere |
| `Resources/Art/khomus.png` | 1200 × 1200 | yes | engraved silver khomus with a steel reed; clean edges on the dark background |
| `Resources/Art/logo.png` | 512 × 512 | yes | silver khomus inside an engraved diamond; no text |
| `Resources/Art/knob.png` | 512 × 512 | yes | lathe-turned silver cap lit from the upper left; no pointer or marking |
| `Resources/Art/ornament.png` | 2400 × 64 | yes | two silver rails with alternating solid and dotted diamonds; Codex compared the first and last columns, and it tiles |

The sizes and alpha were read with `sips`. A scratch composite placed the assets on the
background in the mockup's layout, with dark panels, cyan arcs, the khomus and two bands. It
reads like the mockup: no white fringes, and the silver stands out without glare.

## Not verified

- **The author has not seen the assets.** Phase 04 needs only the file names and sizes, so any
  file can be regenerated later without code changes.
- **Real Liquid Glass over the background:** the composite only imitated glass with flat
  translucent panels. Phase 04 checks the real glass.
